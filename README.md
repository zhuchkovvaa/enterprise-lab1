# Enterprise Lab 1 - React SPA

Лабораторная работа №1 по дисциплине "Веб-программирование".
Разработка одностраничного приложения (SPA) на React + Vite.

## Технологии
- React (Functional Components)
- Vite
- CSS Variables & Flexbox/Grid

## Структура проекта
- `src/components/` - UI компоненты (Header, Hero, ServiceList, Footer)
- `src/data/` - Моковые данные (servicesData.js)
- `src/App.jsx` - Точка сборки приложения

## Запуск
npm install
npm run dev
